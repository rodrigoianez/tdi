# 🖼️ Tratamiento Digital de Imágenes

Repositorio correspondiente a la asignatura **Tratamiento Digital de Imágenes (TDI)** del **Grado en Ingeniería Informática**.

En este proyecto se recopilan las prácticas y ejercicios desarrollados durante la asignatura, centrados en el procesamiento y análisis digital de imágenes.

## 📂 Contenido

El proyecto incluye diferentes funcionalidades relacionadas con el tratamiento digital de imágenes, organizadas en:

* `Include/` — Archivos de cabecera.
* `Source/` — Código fuente.
* `Lib/` — Librerías utilizadas por el proyecto.
* `Run/` — Ejecutables y elementos necesarios para la ejecución.
* `TDI/` — Archivos del proyecto.
* `TDI.sln` — Solución de Visual Studio.

## 🛠️ Tecnologías

* **C++**
* **Visual Studio**
* **OpenCV**
* Git
* GitHub

## 🎯 Objetivos

* Aplicar técnicas de **procesamiento digital de imágenes**.
* Implementar algoritmos de tratamiento y análisis de imágenes.
* Trabajar con imágenes mediante programación en C++.
* Utilizar librerías especializadas como **OpenCV**.
* Analizar y experimentar con diferentes técnicas de visión por computador.

## 💻 Entorno de desarrollo

El proyecto está desarrollado en **C++** utilizando **Visual Studio**.
